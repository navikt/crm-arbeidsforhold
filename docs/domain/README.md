# Domene (SF)

Denne siden samler dokumentasjon for Aa-registeret sitt Salesforce-domene.

Med domene mener vi de interne forretningsområdene og begrepene løsningen bygger på, for eksempel søknad, avtale, vedtak og saksbehandling.

Domeneområdet skal beskrive hva løsningen eier selv, uavhengig av hvilke eksterne systemer vi integrerer med.

## Typiske områder

- Application
- Agreement
- Decision
- Casework
- Felles domenemodell

## Hva hører hjemme her?

- Domenebegreper
- Objektansvar
- Forretningsregler
- Valideringsregler
- Livssyklus og statusmodell
- Hvilke data som er autoritative i Salesforce
- Grense mot integrasjoner og brukerflater

## Viktig prinsipp

Integrasjoner kan bruke domenedata, men skal ikke eie domenelogikken.

Brukerflater kan vise og endre domenedata, men skal ikke definere domenereglene alene.
