# Brukerflater (SF)

Denne siden samler dokumentasjon for brukerflater i Aa-registeret Salesforce-løsningen.

Brukerflater er det mennesker møter direkte, enten de er NAV-ansatte eller eksterne kunder/konsumenter.

Vi skiller mellom interne og eksterne brukerflater.

## Interne flater

Interne flater er brukerflater for NAV-ansatte, for eksempel saksbehandlere og støttepersonell.

Eksempel:

- saksbehandlerflater
- arkiveringshandlinger
- statuspanel
- interne oversikter
- interne flows og Lightning-sider

## Eksterne flater

Eksterne flater er brukerflater for kunder, konsumenter eller andre utenfor NAVs interne saksbehandlerflate.

Eksempel:

- søknadsflater

## Hva hører hjemme her?

- LWC-komponenter
- Lightning pages
- Screen flows
- Brukerflyt
- Synlig status og feilmeldinger
- Rollebasert tilgang knyttet til brukerflate

## Hva hører ikke hjemme her?

- Integrasjonsklienter
- DTO-er
- Ekstern API-kontrakt
- Domeneregler som bør ligge under [Domene](../domain/README.md)

## Merknader ved speiling

- Kilden har «LWC-komponenterLightning pages» som ett punkt. Dette er tolket som to punkter, «LWC-komponenter» og «Lightning pages», og delt opp her. Verifiser mot Confluence.
