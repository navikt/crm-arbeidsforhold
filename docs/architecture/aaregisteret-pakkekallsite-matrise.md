# Pakkekallsite-matrise for Arbeidsforhold / Aa-registeret

**Status:** arbeidsutkast; ikkje komplett dependency-verifikasjon.  
**Kontrollert:** 2026-11-14 frå lokal kjelde.  
**Omfang:** kjente symbolsøk i repo-eigd `force-app/`, med manuell kontroll av dei
konkrete kallstadene nedanfor. Pakkemapper er berre brukte som read-only
referansekjelder.

Denne matrisa skil konkrete produktreferansar frå testoppsett og frå pakkar som
enno ikkje er kartlagde. At eit symbol ikkje vart funne i søket, er ikkje bevis
på at dependency-en er ubrukt: metadata, Flow-konfigurasjon, dynamiske kall,
andre API-symbol eller transitive kontraktar kan framleis vere relevante.
